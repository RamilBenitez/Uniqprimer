## How to Take Good Screenshots

```bash
# On Linux (GNOME), use:
gnome-screenshot -a -f validation/results/screenshots/FILENAME.png
# (-a means area select - drag to select region)

# Or use the Print Screen key, then crop in image viewer

# For terminal screenshots: make the font bigger first
# CTRL + SHIFT + = to zoom in terminal
```
